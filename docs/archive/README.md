# Historical archive

These are **historical artifacts** retained because `AGENTS.md` requires
historical evidence to be preserved. They are **not current authority** and
must not define current Aura semantics. Current authority is:

- language semantics: `/docs/LANGUAGE_SPEC.md`, accepted `/docs/adr/*`
- repository state: `/AGENT_STATE.md`
- active task: `/docs/engineering/CURRENT_HANDOFF.md`

The files here are earlier planning, completion, and readiness snapshots that
used to sit at the repository root. They were moved here so the root holds only
current-authority files. Nothing here is imported by tests, scripts, CI, or the
website.
