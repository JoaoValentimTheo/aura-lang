# Aura 0.0.2

The infrastructure release. **0.0.2 implements the frozen 0.0.1 language
semantics** — there is no language change — and adds portable execution, a
versioned browser Playground, the official website, and release infrastructure.

## What this release adds

* **WebAssembly runtime.** The same interpreter compiles to
  `wasm32-unknown-unknown` as a zero-import module. It reaches no DOM, network,
  storage, filesystem, clock, or JavaScript handle.
* **Host boundary.** Every language-visible interaction with the outside world
  routes through one host contract. Native (`StdHost`) provides the real
  filesystem, clock, and sleep; the browser host (`BrowserHost`) provides
  stdout, stdin, and arguments only, and reports unavailable capabilities as
  `E5002`.
* **Versioned Playground.** A browser Playground that executes the real Aura
  WebAssembly runtime inside a Web Worker. Runtime artifacts are immutable and
  identified by version and SHA-256; the selector chooses exactly the artifact
  that executes. Runaway programs are stopped by terminating the Worker.
* **Official website.** A static, Material 3 website deployed to GitHub Pages at
  <https://joaovalentimtheo.github.io/aura-lang/>.
* **Release infrastructure.** Cross-platform artifacts
  (`x86_64-unknown-linux-gnu`, `aarch64-apple-darwin`,
  `x86_64-pc-windows-msvc`) with SHA-256 checksums.

## What is unchanged

* **Language semantics.** Release 0.0.2 ships the frozen 0.0.1 language
  specification. `aura::LANGUAGE_VERSION` is `0.0.1`; the release version
  `aura::VERSION` is `0.0.2`.
* **Resource limits.** AST nesting 256, call frames 512, range materialization
  10,000,000, runtime value depth 512, and the substrate-calibrated parser
  backstop are unchanged.
* **Diagnostics.** The stable `E####` codes are unchanged.

## Version model

| Identity | Value |
|---|---|
| Release | 0.0.2 |
| Language | 0.0.1 |
| Runtime artifact | 0.0.2 |
| Playground API | 1 |
| Host ABI | 1 |

## Not in this release

Object-oriented constructs, Python/PyO3 interop, data-science/AI APIs, modules,
LSP, debugger, formatter, and package manager are not part of 0.0.2. After this
release the project enters a long language-maturation cycle before any new
paradigm is added.
