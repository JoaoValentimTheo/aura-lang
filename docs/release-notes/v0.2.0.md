# Aura 0.2.0

The **Core-completion** release. Aura **0.2.0** freezes and completes the Aura
Core language. It is a *language* release, so the release and language versions
coincide at `0.2.0`.

## What this release adds

### Collections

* **Generic map keys.** Maps are `{K: V}` where `K` is a key-capable scalar:
  `string`, `int`, or `bool`, or a union every member of which is key-capable.
  `type Map<K, V> = {K: V}` is an ordinary parameterised alias, not new
  grammar. A generic `K` is admissible in a declaration and must be
  key-capable when the generic is instantiated; `Map<float, int>` and
  `Map<[int], int>` are `E3001`. `float`, `none`, containers, structs, enums,
  ranges, and functions are not key-capable. Keys are ordered `int < bool <
  string`, and `1` and `"1"` are distinct keys.
* **`map.items()`.** `m.items()` returns an eager list of two-element
  `[key, value]` lists in ascending key order. `for k in m` still iterates
  keys.
* **Comprehensions.** `[value for pattern in iterable]`,
  `[value for pattern in iterable if filter]`, `{key: value for pattern in
  iterable}`, and the filtered map form. One generator and at most one filter;
  eager; the iterable runs exactly once; the pattern is assertive like `for`;
  bindings do not leak.
* **Collection type coherence.** Literal inference folds every statically
  known element/key/value into a union; a known expected type is checked
  against every component, so `let xs: [int] = [1, "x"]` is rejected rather
  than silently accepted. Typed mutation (`push`, indexed assignment) and
  indexing (`[T][int] → T`, `{K: V}[K] → V`) carry the element contract.
  `get`/`remove`/`first`/`last`/`pop` are honestly dynamic because they can
  return `none`.

### Syntax rules (Core SPEC gaps closed)

* **Statement separators.** A real newline or `;` is required between
  statements and items; the only zero-width end is directly before `}` or EOF.
  Adjacent statements (`1 2`, `let x = 1 let y = 2`) are `E1006`.
* **Numeric underscores.** `_` may appear only between two valid digits of the
  same component (`1_000`, `0xff_ff`, `1e1_0`); `1_`, `1__0`, `0x_ff`, `1e_10`
  are `E1002`.
* **F-strings.** A lone `}` is `E1006`; `}}` is the only literal `}`.
* **Generic-head `::`.** `Result<int, string>::Ok(1)` continues the existing
  qualified-path semantics; the type arguments bind to the enum head.
* **Module paths.** Paths use `::`; the historical dotted `use a.b` spelling is
  removed.

### Modules

* Variant tags are unique **per module**, not globally.
* `pub module` is a real boundary; a descendant may reach an ancestor's
  private items, an ancestor may not reach a descendant's private items.
* `pub use path::Item [as Alias]` re-exports (visibility-checked,
  non-escalating, transitive, terminating).
* `use path as Alias` binds a lexical, resolution-only module alias.
* A type/variant canonical-name collision is rejected deterministically.

### CLI and REPL

* `aura --help`, per-command `--help`, and bare `aura` printing global help;
  usage errors exit 2 on stderr, language diagnostics exit 1.
* `aura run`/`check` require a source (`-` = stdin); program arguments after
  the source may begin with `-`.
* The REPL uses `rustyline` for line editing and session history, handles
  multiline input across delimiter kinds, cancel-on-Ctrl-C, and a single
  `:quit`/`:help` command spelling.

### Playground and website

* A lightweight completion popup and single-buffer find in the Playground
  editor, shared language metadata, and WCAG-AA syntax colours.
* The website presents **0.2.0** as the current stable release.

### Parity and hardening

* Native/WASM differential parity is restored, including the parser's
  container-nesting bound so over-deep grouping reports `E1015` instead of a
  host stack trap.

## Version model

| Identity | Value |
|---|---|
| Release | 0.2.0 |
| Language | 0.2.0 |
| Runtime artifact | 0.2.0 |
| Playground API | 1 |
| Host ABI | 1 |

The historical **0.0.2** (language 0.0.1) and **0.0.1** releases remain
available and frozen; their artifacts are never overwritten.

## Not in this release

Filesystem-backed modules (`mod.aura`), multi-file discovery, the module
graph, package management, async/concurrency, an LSP, a debugger, a formatter,
macros, reflection, dynamic dispatch, and inheritance are not part of 0.2.0.
The filesystem module system is the next development phase.
